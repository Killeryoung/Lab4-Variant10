Для чого потрібна бібліотекаБібліотека працює з неорієнтованими графами. Вона допомагає перевірити, як з'єднані вершини графа.Основні функції\- connectedComponents — визначає, до якої компоненти належить кожна вершина.\- isConnected — перевіряє, чи всі вершини графа пов'язані між собою.\- hasCycle — перевіряє, чи є в графі цикл.\- componentSizes — повертає кількість вершин у кожній компоненті.Як працює бібліотекаПід час виклику функції програма передає бібліотеці:\- n — кількість вершин;\- m — кількість ребер;\- from і to — масиви, які описують, які вершини з'єднані.Вершини нумеруються від 0 до n - 1. Граф неорієнтований: ребро 0-1 означає те саме, що й 1-0.Функції записують результати в масиви або змінні, які передає програма. Пам'ять для цих результатів виділяє сама програма.Файли SDK\- include/GraphConnectivity.h — оголошення функцій бібліотеки.\- lib/GraphConnectivity.lib — файл для підключення бібліотеки під час компонування.\- bin/GraphConnectivity.dll — бібліотека, потрібна програмі під час запуску.Як підключити1\. Додайте папку include до шляхів пошуку заголовків.2\. Підключіть файл GraphConnectivity.h у коді.3\. Додайте GraphConnectivity.lib до компонування проєкту.4\. Покладіть GraphConnectivity.dll поруч із готовим .exe.Результати та помилкиФункції повертають код стану:\- GC\_OK (0) — усе виконано успішно.\- GC\_ERR\_NULL (-1) — не передано обов'язковий вказівник.\- GC\_ERR\_BAD\_ARG (-2) — передано некоректні дані.\- GC\_ERR\_BUFFER\_SMALL (-3) — замалий масив для результату componentSizes.\- GC\_ERR\_INTERNAL (-4) — внутрішня помилка бібліотеки.Максимальна кількість вершин — 1 000 000.Короткий прикладЯкщо граф має вершини 0, 1, 2, 3, 4, 5 та ребра 0-1, 1-2, 3-4, то він складається з трьох компонент:\- {0, 1, 2} — 3 вершини;\- {3, 4} — 2 вершини;\- {5} — 1 вершина.Функція isConnected для такого графа поверне 0, бо граф не є зв'язним. Функція hasCycle поверне 0, бо циклів немає.
