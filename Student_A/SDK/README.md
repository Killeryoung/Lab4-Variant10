## 1. Призначення бібліотеки

GraphPaths - динамічна бібліотека мовою C++, призначена для знаходження найкоротших шляхів у зваженому графі.

Бібліотека реалізує алгоритм Дейкстри, знаходження найкоротшого маршруту, відновлення послідовності вершин та обчислення довжини шляху.

## 2. Склад SDK

- `include/GraphPaths.h` - заголовковий файл з оголошеннями функцій.
- `lib/libGraphPaths.dll.a` - імпортна бібліотека MinGW.
- `bin/libGraphPaths.dll` - динамічна бібліотека Windows.

## 3. Опис API

### dijkstra()

```cpp
int dijkstra(const int* matrix, int n, int source,
             long long* dist, int* parent);
```

Знаходить найкоротші відстані від заданої вершини до інших вершин графа.

Повертає `1` при успішному виконанні та `0` при некоректних вхідних даних.

### reconstructPath()

```cpp
int reconstructPath(const int* parent, int n,
                    int source, int target,
                    int* path, int capacity);
```

Відновлює маршрут від початкової до кінцевої вершини.

Повертає кількість вершин маршруту, `0`, якщо шлях відсутній, або `-1` при помилці.

### shortestPath()

```cpp
int shortestPath(const int* matrix, int n,
                 int source, int target,
                 int* path, int capacity);
```

Знаходить найкоротший маршрут між двома вершинами.

Повертає кількість вершин маршруту, `0`, якщо шлях відсутній, або `-1` при некоректних параметрах.

### pathLength()

```cpp
long long pathLength(const int* matrix, int n,
                     const int* path, int count);
```

Обчислює сумарну вагу ребер заданого маршруту.

Повертає довжину маршруту або `-1` при помилці.

## 4. Вхідні дані та обмеження

Граф задається матрицею суміжності розміром `n × n`.

- `matrix` - покажчик на матрицю суміжності.
- `n` - кількість вершин графа.
- `source` - початкова вершина.
- `target` - кінцева вершина.
- `dist` - масив для збереження відстаней.
- `parent` - масив попередніх вершин.
- `path` - масив для запису маршруту.
- `capacity` - місткість масиву маршруту.
- `count` - кількість вершин у заданому маршруті.

Значення `-1` у матриці означає відсутність ребра. Ваги наявних ребер повинні бути невід'ємними.

Нумерація вершин починається з нуля.

## 5. Обробка помилок

Бібліотека передбачає перевірку некоректних параметрів, зокрема:

- передача `nullptr`;
- некоректна кількість вершин;
- неправильні індекси вершин;
- недостатня місткість масиву маршруту;
- відсутність шляху;
- некоректні ваги ребер.

Функції повертають спеціальні значення відповідно до контракту API.

## 6. Результати тестування

Для тестового графа отримано:

```text
Distances: 0 3 1 4 7
Path 0 -> 4: 0 2 1 3 4
Length: 7
nullptr rejected: 1
```

Найкоротший маршрут від вершини 0 до вершини 4 має довжину 7.

Перевірка передачі `nullptr` пройдена успішно.

## 7. Підключення бібліотеки

**Неявне зв'язування:** підключити `GraphPaths.h`, додати `libGraphPaths.dll.a` до компонування та розмістити `libGraphPaths.dll` поруч із виконуваним файлом.

**Явне зв'язування:** завантажити `libGraphPaths.dll` за допомогою `LoadLibrary()`, отримати адреси функцій через `GetProcAddress()` та після завершення роботи викликати `FreeLibrary()`.

Функції використовують `extern "C"` для забезпечення сумісного інтерфейсу C-ABI.
